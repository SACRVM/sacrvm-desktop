How installing works

One repo, one app, always the same shape — so a URL is enough.

  1. You paste github.com/owner/repo.
  2. The desktop reads owner.github.io/repo/app.json — a fetch, not an execution.
  3. It shows you what the manifest says, and where it came from.
  4. You confirm. Only then is the app's script ever loaded, and only when you first open the app.

An installed app runs its own code in this page. Install what you trust, the way you would a browser extension — the origin is on every tile for exactly that reason.
