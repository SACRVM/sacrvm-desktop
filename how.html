How this works

The long version of About SACRVM DESKTOP. The short one sits behind the (i) in the ribbon — back to the desktop.

So funktioniert's

Die lange Version von „Über SACRVM DESKTOP“. Die kurze steckt hinter dem (i) in der Leiste — zurück zum Desktop.

Whose desktop is this?

Yours, and only in this browser. Your installed apps and settings live in this browser's storage, on this device. Another visitor to this address sees an empty desktop; your phone sees a different one. There is no server and no account — nothing you do here leaves this device unless an app you installed sends it somewhere.

Wessen Desktop ist das?

Deiner, und nur in diesem Browser. Deine installierten Apps und Einstellungen liegen im Speicher dieses Browsers, auf diesem Gerät. Wer diese Adresse sonst besucht, sieht einen leeren Desktop; dein Handy sieht einen anderen. Es gibt keinen Server und kein Konto — nichts, was du hier tust, verlässt dieses Gerät, außer eine App, die du installiert hast, schickt es irgendwohin.

Where do the apps live?

At their own origin — owner.github.io/repo/ — never here. Installing stores the address and the manifest that was read from it, so the author's next release is simply there. Removing an app forgets that address in this browser. Nothing is deleted at the origin, and nothing on GitHub.

Wo leben die Apps?

An ihrer eigenen Herkunft — owner.github.io/repo/ — nie hier. Installieren speichert die Adresse und das Manifest, das dort gelesen wurde, sodass die nächste Version des Autors einfach da ist. Eine App zu entfernen vergisst diese Adresse in diesem Browser. An der Herkunft wird nichts gelöscht, und auf GitHub auch nicht.

And what you write in them?

Also here, in this browser — each app gets its own drawer, and it can only reach its own. Removing an app keeps what it stored, so reinstalling brings your work back; the remove dialog offers to delete it too, and says how much there is. Settings lists the drawers of apps that are gone, in case you want them cleaned up.

Files you save are the exception to the drawers: an app's Open… and Save as… go to one file space every app on this desktop shares — still in this browser, with your device's own files one click away in the same dialog. No app's removal touches it; Settings says how much is in it and is the one place that deletes it.

Und was du darin schreibst?

Auch hier, in diesem Browser — jede App bekommt ihre eigene Schublade und kommt nur an ihre eigene heran. Eine App zu entfernen behält, was sie gespeichert hat, sodass eine Neuinstallation deine Arbeit zurückbringt; der Entfernen-Dialog bietet an, es mitzulöschen, und sagt, wie viel es ist. Die Einstellungen listen die Schubladen von Apps, die weg sind, falls du sie aufräumen willst.

Dateien, die du speicherst, sind die Ausnahme von den Schubladen: Öffnen … und Speichern unter … einer App gehen in einen Dateibereich, den alle Apps auf diesem Desktop teilen — auch der liegt in diesem Browser, und die Dateien deines Geräts sind im selben Dialog einen Klick entfernt. Kein Entfernen einer App berührt ihn; die Einstellungen sagen, wie viel darin liegt, und sind der einzige Ort, der ihn löscht.

Which apps can go on it?

SACRVM APPKIT apps — and only those. Concretely: a repository whose GitHub Pages serves an app.json in its root, next to the one custom element that app is. That manifest is the whole reason a desktop can install something it has never seen.

Any other repository — however good the project — has nothing here to read, and pasting it will politely fail. There is no review queue, no approval and no account. If it has a manifest, it installs; if it has none, there is nothing to install.

Welche Apps passen darauf?

SACRVM-APPKIT-Apps — und nur die. Konkret: ein Repository, dessen GitHub Pages im Stammverzeichnis eine app.json ausliefert, neben dem einen Custom Element, das die App ist. Dieses Manifest ist der ganze Grund, warum ein Desktop etwas installieren kann, das er nie gesehen hat.

Jedes andere Repository — so gut das Projekt auch ist — hat hier nichts zu lesen, und es einzufügen scheitert höflich. Es gibt keine Prüfung, keine Freigabe und kein Konto. Hat es ein Manifest, lässt es sich installieren; hat es keins, gibt es nichts zu installieren.

What installing does

  1. You paste github.com/owner/repo — or pick an app in the App Store.
  2. The desktop reads owner.github.io/repo/app.json — a fetch, not an execution.
  3. It shows you what the manifest says, and where it came from.
  4. You confirm. Only then is the app's script ever loaded, and only when you first open the app.

?install=<url> in the desktop's address does the same by link, which is how you hand somebody an app — the manifest is still shown, and it still waits for their yes.

An installed app runs its own code in this page. Install what you trust, the way you would a browser extension — the origin is on every tile for exactly that reason.

Was Installieren tut

  1. Du fügst github.com/owner/repo ein — oder wählst eine App im App Store.
  2. Der Desktop liest owner.github.io/repo/app.json — ein Abruf, keine Ausführung.
  3. Er zeigt dir, was im Manifest steht und woher es kommt.
  4. Du bestätigst. Erst dann wird das Skript der App überhaupt geladen, und erst, wenn du die App zum ersten Mal öffnest.

?install=<url> in der Adresse des Desktops macht dasselbe per Link — so gibst du jemandem eine App weiter. Das Manifest wird trotzdem gezeigt, und es wartet trotzdem auf ein Ja.

Eine installierte App führt ihren eigenen Code in dieser Seite aus. Installiere, was du vertraust, so wie bei einer Browser-Erweiterung — genau deshalb steht die Herkunft auf jeder Kachel.

Opening apps, from anywhere

The tile is only the first door. Once installed, an app is reachable without going home:

  • The burger — the menu in any app's ribbon lists the whole desktop, in tile order. A window app opens right where you are; what you were doing stays on stage behind it.
  • Ctrl K (⌘K on a Mac) — the command palette, also behind the magnifier in the ribbon. Type a few letters, Enter: the app opens in place.
  • A link — ?app=<id> in the desktop's address opens that window app on arrival; a middle-click on a burger entry lands the same way, in a new tab.

Palette and burger are the kit's — every app on this desktop answers them, current and future ones alike.

Apps öffnen, von überall

Die Kachel ist nur die erste Tür. Einmal installiert, ist eine App erreichbar, ohne zurück zum Start zu gehen:

  • Das Burger-Menü — das Menü in der Leiste jeder App listet den ganzen Desktop, in Kachel-Reihenfolge. Eine Fenster-App öffnet sich genau da, wo du bist; was du gerade machst, bleibt dahinter stehen.
  • Strg K (⌘K auf dem Mac) — die Befehlspalette, auch hinter der Lupe in der Leiste. Ein paar Buchstaben tippen, Enter: Die App öffnet sich an Ort und Stelle.
  • Ein Link — ?app=<id> in der Adresse des Desktops öffnet diese Fenster-App beim Ankommen; ein Mittelklick auf einen Eintrag im Burger-Menü landet genauso, in einem neuen Tab.

Palette und Burger-Menü kommen von der Kit — jede App auf diesem Desktop reagiert darauf, heutige und künftige.

Nothing to open yet?

Open the App Store: the + tile at the end of the grid, then the App Store tab. It lists SACRVM's own apps, and Install runs the ordinary install flow: manifest and origin shown, your confirmation asked. Apps already on this desktop are greyed out.

Or write your own: how an app is built, end to end — a manifest, one custom element, and a template repository to start from (Use this template).

The store's list comes from GitHub: the SACRVM repositories tagged sacrvm-app, each with its manifest read. GitHub is only asked when you open the tab.

Noch nichts zum Öffnen?

Öffne den App Store: die +-Kachel am Ende des Rasters, dann der Tab App Store. Er listet SACRVMs eigene Apps, und Installieren läuft über den normalen Weg: Manifest und Herkunft werden gezeigt, deine Bestätigung wird abgefragt. Apps, die schon auf diesem Desktop sind, sind ausgegraut.

Oder schreib deine eigene: wie eine App gebaut wird, von Anfang bis Ende — ein Manifest, ein Custom Element und ein Vorlagen-Repository zum Starten (Use this template).

Die Liste des Stores kommt von GitHub: die SACRVM-Repositorys mit dem Topic sacrvm-app, jeweils mit gelesenem Manifest. GitHub wird erst gefragt, wenn du den Tab öffnest.
