How this works

The long version. The short one sits behind the (i) in the ribbon — back to the desktop.

Whose desktop is this?

Yours, and only in this browser. Your installed apps and settings live in this browser's storage, on this device. Another visitor to this address sees an empty desktop; your phone sees a different one. There is no server and no account — nothing you do here leaves this device unless an app you installed sends it somewhere.

Where do the apps live?

At their own origin — owner.github.io/repo/ — never here. Installing stores the address and the manifest that was read from it, so the author's next release is simply there. Removing an app forgets that address in this browser. Nothing is deleted at the origin, and nothing on GitHub.

And what you write in them?

Also here, in this browser — each app gets its own drawer, and it can only reach its own. Removing an app keeps what it stored, so reinstalling brings your work back; the remove dialog offers to delete it too, and says how much there is. Settings lists the drawers of apps that are gone, in case you want them cleaned up.

Which apps can go on it?

SACRVM APPKIT apps — and only those. Concretely: a repository whose GitHub Pages serves an app.json in its root, next to the one custom element that app is. That manifest is the whole reason a desktop can install something it has never seen.

Any other repository — however good the project — has nothing here to read, and pasting it will politely fail. This is not a store with a review queue: there is no approval, no account and no list. If it has a manifest, it installs; if it has none, there is nothing to install.

What installing does

  1. You paste github.com/owner/repo.
  2. The desktop reads owner.github.io/repo/app.json — a fetch, not an execution.
  3. It shows you what the manifest says, and where it came from.
  4. You confirm. Only then is the app's script ever loaded, and only when you first open the app.

?install=<url> in the desktop's address does the same by link, which is how you hand somebody an app — the manifest is still shown, and it still waits for their yes.

An installed app runs its own code in this page. Install what you trust, the way you would a browser extension — the origin is on every tile for exactly that reason.
